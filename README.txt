EXOTIC TRACKER - prima versione

Contenuto: diario pasti tramite frase, schede animali, pesate, filtro storico ed esportazione backup.

PUBBLICAZIONE:
1. Estrai lo ZIP sul computer.
2. Carica tutti i file in un repository GitHub pubblico.
3. In GitHub apri Settings > Pages.
4. In Build and deployment scegli Deploy from a branch, branch main e cartella /(root), poi Save.
5. Attendi la pubblicazione: GitHub mostra l'indirizzo HTTPS del sito.
6. Su iPhone apri quell'indirizzo in Safari > Condividi > Aggiungi alla schermata Home.

IMPORTANTE:
- Questa prima versione non usa un'intelligenza artificiale online: riconosce alcune frasi italiane semplici e mostra sempre un'anteprima da controllare prima del salvataggio.
- I dati sono salvati nel browser del dispositivo tramite localStorage. Non si sincronizzano automaticamente tra dispositivi e possono andare persi cancellando i dati del browser. Usa regolarmente Esporta backup.
- Per una vera chat con comprensione libera del linguaggio e sincronizzazione cloud servirà una seconda versione con backend e database.
